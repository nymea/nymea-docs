USB Relay
=========

usbrelay
--------



This plugin eneblas you to control low-cost USB HID relays.

Supported Things
----------------


* USB-Relays

::

   * Discovery setup

::

   * Power on/off


Requirements
------------


* The package 'nymea-plugin-usbrelay' must be installed.


More
----


Examples of USB relay hardware can be found 
`here <http://vusb.wikidot.com/project:driver-less-usb-relays-hid-interface>`__.
