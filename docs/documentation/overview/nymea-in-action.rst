nymea in action
===============

This page collects public examples and community projects showing nymea in real installations. Some
articles are older and may contain outdated installation details, but they still show the kinds of
systems that can be built with nymea.

Smart home with touch screen control panel
------------------------------------------

`Open Source Smart Home with Touchscreen Control Panel <https://www.hackster.io/michael_zanetti/open-source-smart-home-with-touchscreen-control-panel-55e613>`__
shows nymea:core and nymea:app running on Raspberry Pi hardware with a 7" touch screen control panel.
The setup combines lighting, sensors, media control and switches in one local smart-home system.

.. image:: https://hackster.imgix.net/uploads/attachments/650968/main_image_mUT97rqp6F.jpg?auto=compress%2Cformat&w=900&h=675&fit=min
   :alt: Smart home with touch screen control panel
   :width: 200px

Hot tub controller
------------------

`Open Source Hot Tub Controller <https://www.hackster.io/124582/open-source-hot-tub-controller-e0a1f3>`__
shows how nymea can be used to add smart control to an older hot tub. The project uses a Raspberry Pi
with nymea to control the system and send notifications when the water reaches the target temperature.

.. image:: https://hackster.imgix.net/uploads/attachments/682275/img_5724_0bbwEg1rDW.JPG?auto=compress%2Cformat&w=900&h=675&fit=min
   :alt: Hot tub controller
   :width: 200px

DIY sensor station
------------------

`Smart and Private Open Source Sensor Station <https://www.hackster.io/simonstuerz/smart-and-private-open-source-sensor-station-c45788>`__
shows a DIY indoor sensor station built with nymea. The project integrates digital and analog sensors,
local data logging, smart lighting and notifications while keeping the data inside the local system.

.. image:: https://hackster.imgix.net/uploads/attachments/774565/sensorstation_tlPUMd6iXp.jpg?auto=compress%2Cformat&w=900&h=675&fit=min
   :alt: DIY sensor station
   :width: 200px

Tasmota and Tuya light switches
-------------------------------

`SmartLife/Tuya WiFi light switch with Tasmota and nymea <https://www.hackster.io/michael_zanetti/smartlife-tuya-wifi-light-switch-with-tasmota-and-nymea-09a7a6>`__
shows how Tasmota and nymea can be used together with Tuya smart light switches.
